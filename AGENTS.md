# Project layout

This is a single-file web app. Keep `index.html` at the repository root so
GitHub Pages can serve it. The root also contains `spec.md` for the project
specification and `prompts.md` for prompts used in the project.

Save every new file in the appropriate location:

- `00_planning/` for planning notes and sketches.
- `01_data/` for data files.
- `02_validation/` for hand calculations and test cases.
- `03_output/` for screenshots and exported results.

Keep the root limited to the project instructions, specification, prompts, and
the single-file app entry point unless a file is required for project setup.
